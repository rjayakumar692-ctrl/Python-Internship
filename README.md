# Personal Information Manager

## 📌 Project Description

Personal Information Manager is a beginner-friendly Python program that stores and displays personal information.

This project demonstrates basic Python concepts such as:

* Variables
* Data types
* User input
* Input validation
* String methods
* f-strings
* Arithmetic operations
* Comments
* Formatted output

## 🛠️ Technologies Used

* Python 3
* VS Code
* Git
* GitHub

## ▶️ How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python personal_info.py
```

5. Enter your favorite food and favorite color when prompted.

## ✨ Features

* Stores name, age, city, and hobby using variables.
* Accepts favorite food from the user.
* Accepts favorite color from the user.
* Validates empty user input.
* Calculates age in months.
* Uses f-strings for formatted output.
* Uses string methods such as `.strip()` and `.title()`.
* Displays a welcome and goodbye message.

## 🧪 Testing

The program was tested with:

* Normal inputs
* Empty inputs
* Inputs containing extra spaces
* Different food and color values
* Long text inputs
